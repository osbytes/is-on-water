Is this point on water?

Click the map or enter coordinates to check. If it is not water, you can find the nearest shorelines with GET /api/nearest. This instance covers oceans, seas, and inland lakes/reservoirs about 2 km² and larger. Coverage is configurable when self-hosting; approximate, not survey-grade.

Try it

GET /api/water · /api/nearest
